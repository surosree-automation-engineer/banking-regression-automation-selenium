# Banking Platform Regression Automation — Selenium WebDriver
 
Automated regression test for login functionality of a sample banking application.
 
## Tech Stack

- Selenium WebDriver

- Java

- TestNG

- ChromeDriver
 
## Scenarios Automated

- Valid login

- Invalid login handling
 
## Folder Structure

- test-scripts: Contains Selenium automation script

- drivers: Contains browser drivers

- test-data: Test inputs (CSV)

- screenshots: Captured failures for debugging
 
## How to Run

- Update driver path

- Execute login-test.java through TestNG runner
